# Outlier S2S implementation plan

> Execute directly using superpowers:executing-plans. The user delegated the decisions and authorized proceeding on 30 September 2026.

Goal: reusable Outlier projects and exact, manually started Rationale insertion in an associated Edge tab.
Spec: ../specs/2026-09-30-outlier-s2s-design.md
Architecture: React project page, validated IPC, main-process insertion controller, authenticated local pipe, MV3 extension, Windows native host.

## Constraints and review focus

- Preserve the supplied sidebar modifications and all voice functionality.
- No paste, page value assignment, LLM service, automatic submit or live Outlier testing.
- Text remains in memory. Project metadata persists atomically.
- Windows and Edge only for native insertion. Failed checks stop; no blind retries.
- Review cancellation during in-flight native requests, tab/document changes, stale replies, nonempty fields and Unicode/newlines.
