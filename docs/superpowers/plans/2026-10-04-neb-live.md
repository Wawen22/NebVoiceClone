# NEB Live Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for integrated execution and independent review.

**Goal:** Add a universal free conversation section using Neb's profile and selected voice.
**Architecture:** Typed Live decisions and persisted profile configuration in main; an independent PCM conversation controller and React page reuse the existing audio relay and streaming speech player. Browser association accepts generic pages while Outlier insertion retains its safeguards.
**Tech Stack:** Existing Electron, React, TypeScript, Vitest, OpenRouter and Gemini. No new runtime dependencies.
**Spec:** `docs/superpowers/specs/2026-10-04-neb-live-design.md`

## Global constraints

Windows runtime only; keys remain in main; transcripts/audio are not persisted automatically; all cross-environment verification, rsync and main commit rules apply. User delegated choices and immediate execution, so no further approval handoffs.

## Review focus

- Stop or pause during asynchronous reasoning/voice must suppress late playback.
- Remote speech during opening or TTS must cancel safely and retain real history.
- Live, manual speech, S2S and insertion must not overlap.
- Generic websites must associate without requiring a Rationale field.
- Missing packets cannot be interpreted as silence; unknown/late costs remain visible.
