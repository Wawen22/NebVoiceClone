Model Generation
Bridging Quality-Does the model lean on the same stock filler phrase every time it hands off to a tool or larger model, delivered with identical prosody — same pitch, pacing, and cheerfulness on every occurrence — so the wait-filler reads as a canned jingle rather than natural speech?
Looping/LLMism–Does the model overuse LLM-isms (i.e. using recognizable catchphrases, sycophantic behavior) or get stuck repeating the same phrase/question in a tight loop?
Interrupted User–Does the model cut the user off or respond over the user before they finish speaking, creating a disruptive turn-taking experience?
Instruction Following Quality - Does the model fail to align with the user's explicit request — ranging from partially addressing it to completely ignoring, contradicting, or declining a clearly safe instruction?
Inaccuracy–Does the model give incorrect, misleading, or hallucinated information?
Anthropomorphism–Does the model speak as if it's human in an offputting way — expressing personal real-world experiences, memories, or human identity in a way that feels misleading or inappropriate (ex: asking the user to meet up for a coffee, telling the user about the model's own personal experiences with touring Europe, etc.)?
Failed Correction–Does the model fail to incorporate user corrections, continue previous mistakes after being corrected, or exhibits short-term memory loss?
Overacted–Does the model sound overacted or overexpressive — e.g., pitch, pacing, or emotional inflection that exceeds what the subject matter calls for, or shifting tone/emotion too quickly between turns?
Wrong Language–Does the model produce output in a language other than the conversation's expected language?
